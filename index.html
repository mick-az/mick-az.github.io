About

映像の鮮明化や動体検知のアルゴリズムを開発して製品に実装し、特許を取得しました。その後、配信サービスの課金・決済機能、多数の利用者へ同時に配信するバックエンド、Web サービスの検索基盤、求人・採用領域のサービス開発に携わってきました。

現在は LeanTechnica の代表として、業務とシステムの仕組みを目的から整理し、必要な場合に生成 AI や AI エージェントを組み込んだ業務システムを設計・開発しています。

Expertise

  • 画像・動画処理

    映像の鮮明化や動体検知のアルゴリズムを開発し、製品に実装した経験。特許を取得しています。画像や動画を扱う業務の自動化に生かします。

  • 課金・決済

    配信サービスの課金・決済機能を設計・開発した経験。金額や権限の誤りを防ぐ設計と検証の手法を、業務システムにも適用します。

  • ストリーミング

    多数の利用者に同時に配信する Web サービスのバックエンドの経験。負荷と障害に強い構成の設計に生かします。

  • 検索

    Web サービスの検索基盤の経験。情報の分類、探し方、検索結果の検証という観点を、情報設計やコンテンツの企画に生かします。

  • HRTech

    求人・採用の領域の Web サービスに関する業務知識。人事・採用業務の改善に対応します。

  • AI エージェント

    生成 AI の API 連携と、AI エージェントの構築。読み取りは AI に任せ、判断はルールと検証で守る設計を行います。
